Setup Guide

Connect in Minutes

Follow the step-by-step instructions for your platform. Your PC Plus Computing technician will provide your configuration file.

1

Download WireGuard

Download and install the official WireGuard client for Windows from the link above.

2

Import Your Tunnel

Open WireGuard, click Import tunnel(s) from file, and select the .conf file provided by your technician.

3

Activate Connection

Select your tunnel from the list and click Activate. The status will change to "Active" with a green indicator when connected.

1

Install from App Store

Download WireGuard from the Mac App Store using the link in the download section above.

2

Import Configuration

Open WireGuard, click Import Tunnel(s) from File, and select your .conf file. Allow the VPN configuration when prompted.

3

Connect

Toggle the switch next to your tunnel name to activate the VPN. You'll see the WireGuard icon appear in your menu bar.

1

Install the App

Download WireGuard from the App Store (iOS) or Google Play Store (Android).

2

Scan Your QR Code

Open the WireGuard app, tap the + button, and select Create from QR code. Point your camera at the QR code provided by your technician.

3

Connect

Name your tunnel (e.g., "PC Plus VPN") and toggle the switch to connect. Allow VPN configuration when prompted by your device.

1

Install WireGuard Tools

Install the WireGuard package for your distribution:
sudo apt install wireguard (Debian/Ubuntu)
sudo dnf install wireguard-tools (Fedora/RHEL)

2

Place Configuration File

Copy the .conf file provided by your technician to the WireGuard directory:
sudo cp pcplus-vpn.conf /etc/wireguard/wg0.conf

3

Start the Tunnel

Activate the tunnel and optionally enable it at boot:
sudo wg-quick up wg0
sudo systemctl enable wg-quick@wg0

Security

Keep Your Connection Secure

Follow these best practices to maintain the highest level of protection.

Protect Your Config File

Your VPN configuration file contains private keys. Store it securely, never upload it to cloud storage, and delete it from email after importing.

Never Share Credentials

Your VPN credentials are unique to you. Sharing them compromises your security and the entire network. Each user gets their own configuration.

Report Suspicious Activity

If you suspect unauthorized access or notice unusual behavior on your VPN connection, contact us immediately. We monitor 24/7 and can revoke access instantly.

Keep Client Updated

Always run the latest version of the WireGuard client. Updates include security patches and performance improvements critical for your protection.
